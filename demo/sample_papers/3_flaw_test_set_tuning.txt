A Lightweight Transformer for Sentiment Analysis. We propose a compact transformer that outperforms strong baselines on two benchmarks. Input text is lower-cased and truncated to 256 tokens. We train for 20 epochs with a batch size of 32 on a single GPU. We selected the best checkpoint based on the test accuracy at each epoch. All baselines received the same hyperparameter search budget. Section 5 reports the main results.
